# 🧳 Mastercard Concierge App

Aplicativo mobile desenvolvido para oferecer uma experiência de **concierge digital**, permitindo que usuários encontrem serviços, façam solicitações e tenham acesso a benefícios de forma prática e intuitiva.

## 📱 Sobre o projeto

O **Mastercard Concierge** foi desenvolvido com o objetivo de centralizar serviços de concierge em uma aplicação mobile moderna, proporcionando ao usuário uma experiência simples, rápida e personalizada.

A aplicação permite que o usuário navegue pelos serviços disponíveis, consulte informações e realize solicitações diretamente pelo aplicativo.

## ✨ Funcionalidades

* 🔐 Autenticação de usuários
* 👤 Gerenciamento de perfil
* 🏨 Busca e consulta de serviços
* 🍽️ Serviços de restaurantes e experiências
* ✈️ Auxílio relacionado a viagens
* 🎫 Solicitação de experiências e benefícios
* 📋 Visualização de solicitações
* 🔔 Notificações
* 📱 Interface responsiva e adaptada para dispositivos móveis

## 🚀 Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/mastercard-concierge.git
```

### 2. Acesse a pasta

```bash
cd mastercard-concierge
```

### 3. Instale as dependências

```bash
npm install
```

ou:

```bash
yarn
```

### 4. Inicie o projeto

```bash
npx expo start
```

Depois, você poderá executar o aplicativo utilizando:

* 📱 Expo Go
* 🤖 Android Emulator
* 🍎 iOS Simulator
* 🌐 Web

## 🔑 Configuração

Caso o projeto utilize variáveis de ambiente, crie um arquivo `.env` na raiz:
